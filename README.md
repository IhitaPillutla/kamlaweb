# kamlaweb

A deliberately early-2000s paranormal archive website for a **KAMLA transmedia campaign**.

## Concept
The site behaves like an old independent occult-research mirror that has collected government-style case records, witness accounts, photographs, recovered media, theories, and user-submitted leads concerning the fictional Kamla case.

Visual direction: amateur paranormal web circa 2002–2005 — black backgrounds, tiny text, neon links, visitor counters, webrings, broken media, questionable HTML, and unsettling details hidden inside ordinary-looking pages.

## Current sections
- Home / Latest
- Case File 08-K
- Kamla / Pandit
- Recovered Media
- Theory Board
- Join the Search

Theory and lead forms currently save only to browser localStorage.

## Deploy
This is a static site. Put `index.html` at the repository root and enable GitHub Pages from `main` / root.
